## Global Options

**--background, -b**: run download in background (exit immediately without progress display)

**--cookie**="": HTTP cookie(s) for authentication (format: 'name=value', can be specified multiple times)

**--cookies-from**="": import cookies from browser cookie file (Firefox, Chrome, Netscape) or 'auto' for auto-detection

**--daemon-uri**="": daemon URI (unix:///path, tcp://host:port, pipe://name)

**--debug, -d**: enable debug logging for troubleshooting

**--download-path, -l**="": set the path where downloaded file should be saved (default: $WARPDL_DEFAULT_DL_DIR or current directory)

**--file-name, -o**="": explicitly set the name of file (determined automatically if not specified)

**--force-parts, -f**: forceful file segmentation (default: true)

**--input-file, -i**="": read URLs from input file (one URL per line, # for comments)

**--max-connection, -x**="": specify the number of maximum parallel connection (default: 24)

**--max-parts, -s**="": to specify the number of maximum file segments (default: 200)

**--max-retries**="": maximum retry attempts for transient errors (0 = unlimited) (default: 5)

**--no-work-steal**: disable work stealing (fast parts taking over slow part ranges)

**--overwrite, -y**: overwrite existing file at destination path

**--priority**="": queue priority: high, normal, low (default: normal) (default: normal)

**--proxy**="": proxy server URL (http://host:port, https://host:port, socks5://host:port)

**--retry-delay**="": base delay between retries in milliseconds (default: 500)

**--schedule**="": cron expression for recurring download schedule (e.g., "0 2 * * *" = daily 2 AM)

**--speed-limit, -S**="": limit download speed (e.g., 1MB, 512KB, 0 for unlimited)

**--ssh-key**="": path to SSH private key file for SFTP downloads (default: ~/.ssh/id_ed25519 or ~/.ssh/id_rsa)

**--start-at**="": schedule download to start at a specific time (format: YYYY-MM-DD HH:MM)

**--start-in**="": schedule download to start after a relative duration (e.g., 2h, 30m, 1h30m); mutually exclusive with --start-at

**--time-taken, -e**: 

**--timeout, -t**="": per-request timeout in seconds (0 = no timeout) (default: 30)

**--user-agent**="": HTTP user agent to use for downloading (default: warp)

## auth

Manage OAuth credentials for warpdl plugins

### login

Log in to an OAuth-backed plugin

**--as**="": account label (default "default")

**--device**: use device-code flow instead of loopback PKCE

**--no-browser**: print the authorize URL instead of opening a browser

**--scopes**="": scope subset to request (default: manifest scopes)

### list

List stored OAuth credentials

### logout

Forget a stored OAuth credential

**--as**="": account label (default "default")

### status

Report whether a plugin has stored credentials (exit 0 iff authenticated and not expired)

**--as**="": account label (default "default")
